# اذان — اوقات شرعی 🕋

این یک **اپلیکیشن سادهٔ اوقات شرعی** برای اندروید است که به‌طور ویژه برای **یک شخص مسن و مبتلا به آلزایمر** ساخته شده؛ هدف، سادگی و استفادهٔ راحت است: بدون منوی پیچیده، با فونت‌های بزرگ، و نمایش خودکار اوقات نماز بر اساس موقعیت مکانی.

</div>

## دانلود و نصب

1. به بخش [Releases](../../releases) این مخزن بروید.
2. آخرین نسخه را دانلود کنید (فایل `apk.`).
3. فایل را روی گوشی اندروید باز کنید و **نصب** (Install) را بزنید. در صورت نیاز، اجازهٔ «نصب از منابع ناشناخته» را بدهید.

> فایل APK داخل کد مخزن نیست و هر بار توسط گیتهاب‌اکشن ساخته و به Release همان نسخه پیوست می‌شود.

## ساخت و انتشار نسخهٔ جدید

با هر push به شاخهٔ `main`، گیتهاب‌اکشن یک APK می‌سازد و در Artifacts آکشن ذخیره می‌کند.

برای انتشار رسمی، کافی است یک تگ بزنید:

```bash
git tag v1.1.0
git push origin v1.1.0
```

اکشن خودش APK را می‌سازد و با همان نام تگ یک Release منتشر می‌کند.

### امضای نسخهٔ انتشار (اختیاری)

پیش‌فرض، APK با کلید debug امضا می‌شود (برای استفادهٔ شخصی کافی است). اگر خواستید با کلید واقعی امضا شود، سه Secret به مخزن اضافه کنید:

| Secret | مقدار |
|---|---|
| `KEYSTORE_BASE64` | فایل keystore به‌صورت base64 (`base64 -w0 azan-release.jks`) |
| `KEYSTORE_PASSWORD` | رمز keystore |
| `KEY_ALIAS` / `KEY_PASSWORD` | نام و رمز کلید |

## ساخت محلی

پیش‌نیاز: JDK 21، Android SDK (platform 36)، Node.js 24

```bash
npm ci
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

## ساختار پروژه

پروژه‌ای مبتنی بر [Capacitor](https://capacitorjs.com) است: رابط کاربری وب (React + Vite) داخل WebView اجرا می‌شود و پلاگین‌های نیتیو (نوتیفیکیشن اذان، موقعیت مکانی، ویبره و…) از طریق Capacitor در دسترس‌اند.

- `app/` — ماژول اندروید (Gradle)
- `app/src/main/assets/public` — فایل‌های وبِ همگام‌شدهٔ اپ
- `capacitor-cordova-android-plugins` — لایهٔ سازگاری کوردوا
- `.github/workflows/android.yml` — ساخت خودکار APK و انتشار در Release
